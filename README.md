Forecasts each hour of GTA VI's launch day on Twitch from the first hour's viewer count, calibrated on 19 past big game launches: a per-hour regression of log viewership ratios on launch size, with honest cross-launch quantile spreads. Practice pooled pinball loss 0.1795 on the log scale vs 0.3871 for the flat house baseline.
